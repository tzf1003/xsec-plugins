# 插件设置规范

资产发现插件的设置页位于“设置 → 插件 → 资产发现”。

## 默认收集配置

- 选择默认数据源：鹰图 Hunter 或 FOFA + 天眼查。
- 为所选数据源配置 API Host；Skill 路径可按工作区需要填写。
- 保存后，新的收集任务使用这组默认配置。

## 凭据

Hunter、FOFA 与天眼查凭据由宿主系统密钥库保存。插件前端只展示配置状态，并提供保存和清除操作；设置读取未完成时不会启用这些操作。

## 收集操作台

收集任务、资产搜索、导入和任务筛选位于插件主界面。任务详情会显示任务记录中保存的访问模式；未记录该字段的历史任务会明确标示为未记录。
